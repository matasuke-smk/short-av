# X アカウント プロフィール素材

DMM アフィリエイトに X アカウントを運営サイトとして登録するための素材と、設定の手順。

## 画像

| ファイル | 用途 | サイズ |
|---|---|---|
| `icon.png` | プロフィール画像（X 上では円形に切り抜かれる） | 400×400 |
| `header.png` | ヘッダー画像 | 1500×500 |

元データは `icon.svg` / `header.svg`。審査とアカウント凍結を避けるため、性的な表現は入れていない。

## 審査前のチェックリスト

- [ ] プロフィール画像・ヘッダー・名前・自己紹介・ウェブサイトを設定
- [ ] 上の固定ポストを投稿してプロフィールに固定
- [ ] 作品紹介の投稿を5件以上（`/admin/x-posts` の候補をそのまま投稿でよい）
- [ ] 設定 →「プライバシーと安全」→「あなたのポスト」→「ポストするメディアをセンシティブな内容を含むものとして設定する」をオン
- [ ] DMM アフィリエイトの管理画面で、この X アカウントを運営サイトとして申請
- [ ] 承認後、管理画面の「画像利用ルール」で SNS に使える画像の種類を確認してから画像を添付する
