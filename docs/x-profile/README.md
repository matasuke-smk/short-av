# X アカウント プロフィール素材

DMM アフィリエイトに X アカウントを運営サイトとして登録するための素材と、設定の手順。

## 画像

| ファイル | 用途 | サイズ |
|---|---|---|
| `icon.png` | プロフィール画像（X 上では円形に切り抜かれる） | 400×400 |
| `header.png` | ヘッダー画像 | 1500×500 |

元データは `icon.svg` / `header.svg`（PNG は `node -e "require('sharp')('docs/x-profile/header.svg').png().toFile('docs/x-profile/header.png')"` で作り直せる）。審査とアカウント凍結を避けるため、性的な表現は入れていない。
2026-10-08: 同人誌に対応して作り直し（ユーザーと相談して決定）。アイコンは文字だけ（「Short」白・「AV」赤の2段）、ヘッダーは中央にロゴ（赤い角丸に白い再生ボタン）＋「Short AV」、キャッチコピー「動画も同人誌も、スワイプで見つかる。」、背景にうっすら再生ボタンと開いた本の模様。

## プロフィール

**名前**（2026-10-08 に変更。サイト・ロゴの表記「Short AV」に揃え、カタカナでも検索できるよう併記）

```
Short AV（ショートAV）
```

@ のユーザー名（ハンドル）は変えない（過去の投稿のリンクや DMM アフィリエイトへの登録と合わなくなるため）。

**自己紹介**（101/160文字。2026-10-10 に短縮: X のアプリは自己紹介を3〜4行で切って「…」にするため、以前の150文字超の文では「ブラウザで開くと快適」の前で切れていた（iPhone・Android の実機で確認）。本文を短くし、ブラウザの一言は改行して「※仕組み上」を付けた（ユーザーの案）。2026-10-10 に iPhone・Android で確認: アプリは3行目の末尾までを表示し、それ以降が「…」になる。この文では1〜3行目（本文・ブラウザ・18歳未満）が見え、#PR の行だけ折りたたまれる）

```
FANZAのサンプル動画と同人誌の試し読みをスワイプで次々チェック。毎日更新。
※仕組み上、ブラウザで開くと快適です
※18歳未満はフォローご遠慮ください
※DMM/FANZAアフィリエイト利用 #PR
```

自己紹介を変えるときは、見せたい内容を3行目までに入れる（アプリは3行目の末尾までしか見せない）。

**ウェブサイト**

```
https://short-av.com
```

## 固定ポスト

2026-10-10: 固定ポストはサイトの紹介から「ペニスサイズ偏差値チェッカー」の告知に差し替え（スワイプ画面以外の主力ツール。Bing で「ちんこ 偏差値チェッカー」の検索が多い）。以前の文は下に残す。

```
【ちんこ偏差値チェッカー】
長さと太さを入れるだけで、日本人の平均と比べた偏差値と、100人中なん位かが分かります。
・登録不要・匿名
・cm でも mm でも OK
・コンドームのサイズの目安も表示
👇
https://short-av.com/articles/size-comparison-tool

※18歳未満の方はご利用いただけません
#PR
```

以前の固定ポスト（サイトの紹介）:

```
【Short AV について】
FANZAのサンプル動画を、縦スワイプで次々チェックできるサイトです。

・人気作／新作を毎日更新
・会員登録不要
・Xのアプリ内より、Chrome/Safariで開くのがおすすめ

▶ https://short-av.com

※18歳未満の方はご利用いただけません
※DMM/FANZAアフィリエイトを利用しています
#PR #FANZA
```
