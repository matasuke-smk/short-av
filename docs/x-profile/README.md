# X アカウント プロフィール素材

DMM アフィリエイトに X アカウントを運営サイトとして登録するための素材と、設定の手順。

## 画像

| ファイル | 用途 | サイズ |
|---|---|---|
| `icon.png` | プロフィール画像（X 上では円形に切り抜かれる） | 400×400 |
| `header.png` | ヘッダー画像 | 1500×500 |

元データは `icon.svg` / `header.svg`（PNG は `node -e "require('sharp')('docs/x-profile/header.svg').png().toFile('docs/x-profile/header.png')"` で作り直せる）。審査とアカウント凍結を避けるため、性的な表現は入れていない。
2026-10-08: 同人誌に対応して作り直し（ユーザーと相談して決定）。アイコンは文字だけ（「Short」白・「AV」赤の2段）、ヘッダーは中央にロゴ（赤い角丸に白い再生ボタン）＋「Short AV」、キャッチコピー「動画も同人誌も、スワイプで見つかる。」、背景にうっすら再生ボタンと開いた本の模様。

## プロフィール

**名前**（2026-10-08 に変更。サイト・ロゴの表記「Short AV」に揃え、カタカナでも検索できるよう併記）

```
Short AV（ショートAV）
```

@ のユーザー名（ハンドル）は変えない（過去の投稿のリンクや DMM アフィリエイトへの登録と合わなくなるため）。

**自己紹介**（95/160文字。2026-10-10 に短縮: X のアプリは自己紹介を3〜4行で切って「…」にするため、以前の150文字超の文では「ブラウザで開くと快適」の前で切れていた（iPhone・Android の実機で確認）。本文を1段落50文字程度にし、肝心の一言を前に）

```
FANZAのサンプル動画と同人誌の試し読みをスワイプで次々チェック。毎日更新。ブラウザで開くと快適です。
※18歳未満はフォローご遠慮ください
※DMM/FANZAアフィリエイト利用 #PR
```

4行にしたい場合の別案（109文字。行が増えるぶん切れやすい）:

```
FANZAの人気作をサンプル動画＆同人誌の試し読みで紹介。スワイプで次々チェック、毎日更新。
※Xのアプリ内よりブラウザで開くと快適
※18歳未満はフォローご遠慮ください
※DMM/FANZAアフィリエイト利用 #PR
```

**ウェブサイト**

## 固定ポスト

2026-10-09: X のアプリ内ブラウザは表示が狭くスワイプもしづらいので、ブラウザで開く案内を追加（投稿文にも「※ブラウザで開くと快適です」を入れている）。

```
【Short AV について】
FANZAのサンプル動画を、縦スワイプで次々チェックできるサイトです。

・人気作／新作を毎日更新
・会員登録不要
・Xのアプリ内より、Chrome/Safariで開くのがおすすめ

▶ https://short-av.com

※18歳未満の方はご利用いただけません
※DMM/FANZAアフィリエイトを利用しています
#PR #FANZA
```
