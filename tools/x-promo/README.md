# X投稿支援ツール

short-av.comの作品をXで宣伝するためのCLIツールです。

## 機能

1. **作品情報取得**: Supabaseから動画情報を取得
2. **紹介文自動生成**: X投稿用のテキストを複数テンプレートから生成
3. **クリップボードコピー**: 生成したテキストを自動でコピー
4. **サンプル動画ダウンロード**: X投稿用に動画をダウンロード

## 使い方

プロジェクトルートから実行:

```bash
# ランダムな動画を選択
npm run x-promo

# ランキング上位から選択
npm run x-promo:ranking

# 動画もダウンロード
npm run x-promo:download
```

または直接実行:

```bash
# ランダムな動画を選択
node tools/x-promo/index.js

# ランキング上位から選択
node tools/x-promo/index.js --ranking

# 指定IDの動画を選択
node tools/x-promo/index.js --id abc12345

# サンプル動画もダウンロード
node tools/x-promo/index.js --download

# 組み合わせ
node tools/x-promo/index.js --ranking --download
```

## オプション

| オプション | 短縮形 | 説明 |
|-----------|--------|------|
| `--random` | - | ランダムな動画を選択（デフォルト） |
| `--ranking` | - | ランキング上位から選択 |
| `--id <id>` | `-i` | 指定したDMMコンテンツIDの動画を選択 |
| `--download` | `-d` | サンプル動画をダウンロード |
| `--help` | `-h` | ヘルプを表示 |

## ダウンロードした動画

`--download`オプションを使用すると、動画は以下に保存されます:

```
tools/x-promo/downloads/
```

## X投稿の流れ

1. ツールを実行して動画を選択
2. 紹介文が自動でクリップボードにコピーされる
3. （オプション）`--download`でサンプル動画をダウンロード
4. Xを開いて新規投稿を作成
5. テキストを貼り付け (Ctrl+V)
6. サンプル動画を添付
7. 投稿！

## 注意事項

- 投稿には必ず `#PR` タグを含めてください（ステマ規制対応）
- サンプル動画のダウンロードはDMMの利用規約に従ってください
- 過度な投稿はスパム扱いされる可能性があります
